# Agente-de-Automa-o-para-Grandes-Fluxos-de-Dados
Agente em Python que lê dados de **múltiplos formatos** (CSV, XML, SQLite, DOCX, Markdown), limpa, calcula e grava um relatório processado em CSV. Funciona com dados "do mundo real": números no formato brasileiro, CSV do Excel (`;` e Latin-1) e arquivos grandes processados em blocos.
